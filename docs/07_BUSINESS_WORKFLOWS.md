# Business Workflows

## 1. CRM & Sales Workflow

Customer Journey:
`Lead` -> `Enquiry` -> `Quotation` -> `Sales Order` -> `Production/Stock Allocation` -> `Delivery` -> `Invoice` -> `Payment`

## 2. Procurement Workflow

Requirement Journey:
`Department Demand` -> `Purchase Requisition (PR)` -> `Request for Quotation (RFQ)` -> `Vendor Quotation Comparison` -> `Purchase Order (PO)` -> `Goods Receipt Note (GRN)` -> `Quality Check (QC)` -> `Inventory update` -> `Purchase Invoice` -> `Payment`

## 3. Production Workflow

Manufacturing Journey:
`Sales Order` -> `Production Planning` -> `Bill of Materials (BOM) Generation` -> `Material Requirement Planning` -> `Material Issue from Store` -> `Production/Assembly` -> `Quality Control (QC)` -> `Finished Goods to Warehouse`

## 4. Ticketing & Customer Service

Support Journey:
`Customer Issue` -> `Ticket Created` -> `Assign to Technician` -> `In Progress` -> `Resolution` -> `Customer Feedback` -> `Closed`
