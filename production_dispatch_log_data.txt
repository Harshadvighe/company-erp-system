1. DISPATCH LOG MODULE - APPLIED FIELD STRUCTURE & SPECIFICATION
----------------------------------------------------------------------------------------------------
Field Key        | Field Label / Header     | Data Type | UI Control / Source | Required | Description / Options
----------------------------------------------------------------------------------------------------
dispatchCode     | Dispatch Code            | String    | Auto Sequence       | YES      | Unique reference voucher: DSP-YYYY-XXXX (e.g. DSP-2026-0001)
productId        | Product ID / Serial No   | String    | Selection / Badge   | YES      | Serialized hardware unit ID (e.g. PRD-2026-VFD-0101)
batchNumber      | Batch Number             | String    | Read-only Reference | YES      | Manufacturing batch lot (e.g. BATCH-20260917_193942)
productName      | Product Name / Model     | String    | Read-only Reference | YES      | Product title (e.g. Automatic Triplex VFD Booster Pump Panel)
department       | Destination Department   | String    | Dropdown Options    | YES      | Destination routing department:
                 |                          |           |                     |          |  1. Panel Department
                 |                          |           |                     |          |  2. Tech Support Department
                 |                          |           |                     |          |  3. Finished Goods Warehouse
                 |                          |           |                     |          |  4. Client Site Direct
dispatchTime     | Dispatch Timestamp       | DateTime  | System Generated    | YES      | Sign-off date and time (YYYY-MM-DD HH:MM:SS)
dispatchedBy     | Dispatched By / Sign-off | String    | User Profile / Text | YES      | Name of QC Inspector or Production Coordinator
description      | Dispatch Memo / Notes    | String    | Multi-line Textarea | YES      | Functional pass notes, routing memo & packaging notes
status           | Dispatch Status          | String    | System Badge        | YES      | DISPATCHED, IN_TRANSIT, RECEIVED_BY_DEPT, DELIVERED
notes            | Internal / Courier Notes | String    | Text Input          | NO       | Client tag, transit precautions, or shipping airway bill
